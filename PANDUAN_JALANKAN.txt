Audio-Driven IoT Task Scheduler — Tim Peneliti Dewantara
Universitas Negeri Malang (UM)
ARSITEKTUR RESMI: FULL LIGHTGBM + ADAPTIVE PREEMPTIVE SCHEDULER + RPI 5
================================================================================

Paket ini berisi seluruh sistem terintegrasi kecerdasan buatan berbasis penuh
LightGBM (Full LightGBM Architecture), engine penjadwalan tugas adaptif dengan
preemption kooperatif (adits_adaptive_scheduler.py), validasi uji-t berpasangan,
engine sinkronisasi DSP Chroma, pengujian edge computing di Raspberry Pi 5,
dataset evaluasi, dan model siap jalan untuk robot tari humanoid KRSTI.

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
CARA MENJALANKAN SISTEM DI WINDOWS (LAPTOP / PENGEMBANG):
--------------------------------------------------------------------------------
1. Instalasi dependensi (cukup sekali):
   pip install -r requirements.txt

2. Menjalankan Kontroler Terpadu (Voice AI + Scheduler + DSP + Dance AI):
   python adits_unified_voice_dsp_internal.py

   Perintah Suara yang Didukung (Ucapkan dengan tegas di mikrofon):
   - "MULAI"   -> Memulai musik tari & sinkronisasi AI DSP (Prioritas P1)
   - "STOP"    -> Memotong task & menghentikan robot seketika (Prioritas P0 Preemptive)
   - "LANJUT"  -> Melanjutkan tarian dari posisi terakhir (Prioritas P1)
   - "BERDIRI" -> Menggerakkan robot ke posisi berdiri siap tari (Prioritas P2)
   - "DUDUK"   -> Menggerakkan robot ke posisi duduk istirahat (Prioritas P2)

3. Menjalankan Uji-t Berpasangan (Statistika Akademis):
   python benchmark_scheduler_ttest.py

--------------------------------------------------------------------------------
CARA MENJALANKAN SISTEM DI RASPBERRY PI 4 (EDGE EMBEDDED ROBOT):
--------------------------------------------------------------------------------
1. Salin folder ADITS_ROBOT_TARI_SIAP_PAKAI ke Raspberry Pi 4 (via Flashdisk / SCP).
2. Buka terminal di Raspberry Pi 4 dan jalankan script setup:
   chmod +x setup_rpi4.sh
   ./setup_rpi4.sh

3. Reboot Pi sekali agar izin USB Serial (U2D2) aktif:
   sudo reboot

4. Masuk ke folder & aktifkan virtual environment:
   cd ~/ADITS_ROBOT_TARI_SIAP_PAKAI
   source venv/bin/activate

5. Jalankan pengujian hardware diagnostik:
   python test_rpi4_hardware.py
   python test_dynamixel_xl320_scan.py (Scan & tes kedip LED servo XL-320)

6. Jalankan Kontroler Terpadu di Raspberry Pi 4:
   python adits_unified_voice_dsp_internal.py
   (Baca panduan lengkap di: PANDUAN_RASPBERRY_PI4.md)

--------------------------------------------------------------------------------
CARA MENJALANKAN SISTEM DI RASPBERRY PI 5 (EDGE EMBEDDED ROBOT):
--------------------------------------------------------------------------------
1. Buka terminal di Raspberry Pi 5 dan jalankan script setup:
   chmod +x setup_rpi5.sh
   ./setup_rpi5.sh

2. Masuk ke virtual environment:
   source venv/bin/activate

3. Jalankan pengujian hardware diagnostik:
   python test_rpi5_hardware.py

4. Jalankan Kontroler Terpadu di Raspberry Pi 5:
   python adits_unified_voice_dsp_internal.py
   (Baca panduan lengkap di: PANDUAN_RASPBERRY_PI5.md)

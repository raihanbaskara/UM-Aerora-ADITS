================================================================================
PAKET RESMI ADITS ROBOT SENI TARI (KRSTI) - SIAP PAKAI & AUDIT
Audio-Driven IoT Task Scheduler — Tim Peneliti Dewantara
Universitas Negeri Malang (UM)
================================================================================

Paket ini berisi sistem terintegrasi kecerdasan buatan berbasis LightGBM,
engine penjadwalan tugas adaptif dengan preemption kooperatif
(adits_adaptive_scheduler.py), validasi uji-t berpasangan, antarmuka Web Hub
(run_web_dashboard.py), skrip instalasi universal Raspberry Pi (setup_raspy.sh),
serta model siap pakai untuk robot tari humanoid KRSTI.

--------------------------------------------------------------------------------
STRUKTUR FOLDER MODULAR (DOMAIN-DRIVEN ORGANIZATION):
--------------------------------------------------------------------------------
[1. DIREKTORI ROOT (EKSEKUSI & ANCHOR)]
- run_web_dashboard.py            : Entry-point Web Telemetry Dashboard (Port 5000)

================================================================================
PAKET RESMI ADITS ROBOT SENI TARI (KRSTI) - SIAP PAKAI & AUDIT
Audio-Driven IoT Task Scheduler — Tim Peneliti Dewantara
Universitas Negeri Malang (UM)
================================================================================

Paket ini berisi sistem terintegrasi kecerdasan buatan berbasis LightGBM,
engine penjadwalan tugas adaptif dengan preemption kooperatif
(adits_adaptive_scheduler.py), validasi uji-t berpasangan, antarmuka Web Hub
(run_web_dashboard.py), skrip instalasi universal Raspberry Pi (setup_raspy.sh),
serta model siap pakai untuk robot tari humanoid KRSTI.

--------------------------------------------------------------------------------
DAFTAR FILE DI DALAM PAKET:
--------------------------------------------------------------------------------
[1. KONTROLER UTAMA & PENJADWAL ADAPTIF]
- run_web_dashboard.py            : Entry-point Web Telemetry Dashboard (Port 5000)
- web/                            : Aplikasi Web Telemetry Dashboard (Flask + WebSocket)
- adits_unified_voice_dsp_internal.py : Kontroler Utama Berbasis Terminal (Voice AI + DSP)
- adits_adaptive_scheduler.py     : Engine Penjadwal Prioritas (P0 s/d P3) min-heap
- posture_lookup_decoder.py       : Decoder pemetaan 15 sudut servo fisik robot tari
- gerakan_baru/                   : 16 file CSV sekuens koreografi gerak tari robot

[2. VALIDASI STATISTIKA AKADEMIS & BENCHMARK]
- benchmark_scheduler_ttest.py    : Skrip Uji-t Berpasangan (N=30) Adaptif vs Statis
- hasil_uji_t_scheduler.xlsx      : Rekap data & kalkulasi uji-t (t=20.34, p=1.04e-18)
- scheduler_ttest_comparison.png  : Grafik visualisasi komparasi waktu respons (Boxplot)
- eval_buffer_duration_sensitivity.py  : Skrip uji sensitivitas panjang buffer audio
- hasil_sensitivitas_buffer_audio.xlsx : Data hasil akurasi per durasi buffer

[3. DEPLOYMENT EMBEDDED RASPBERRY PI (UNIVERSAL PI 4 & PI 5)]
- setup_raspy.sh                  : Skrip bash instalasi otomatis 1-klik (Universal)
- test_hardware.py                : Skrip diagnostik CPU, suhu, ALSA mic, U2D2, dan latensi
- test_dynamixel_xl320_scan.py    : Skrip scanner & uji kedip LED servo Dynamixel XL-320
- run_raspy.sh                    : Skrip shortcut menjalankan sistem di Raspberry Pi
- PANDUAN_RASPBERRY_PI.md         : Panduan langkah lengkap eksekusi di Raspberry Pi
- requirements.txt                : Daftar pustaka dependensi Python

[4. MODEL KECERDASAN BUATAN (.PKL)]
- model_command_classifier_5kelas.pkl     : Model Voice AI Tuned LightGBM (Akurasi 97.33%)
- model_robot_tari_lightgbm_95percent.pkl : Model Dance AI LightGBM (Akurasi 94.62% ~ 95%)
- confusion_matrix_command_5kelas.png     : Matriks konfusi model Voice AI 97.33%

[5. DOKUMENTASI & DATASET]
- README.md                       : Dokumentasi utama repositori
- DOKUMEN_AUDIT_DAN_LAPORAN_SISTEM.md : Matriks kepatuhan proposal riset PKM-KC
- DOKUMENTASI_INSTALASI_DAN_PENGUJIAN/ : Galeri 8 screenshot pengujian nyata di Pi 4
- dataset_perintah_suara_5kelas_realistis.xlsx : Dataset pelatihan perintah suara
- dataset_robot_tari_3detik_lengkap_detail_pose.xlsx : Dataset pemetaan pose tari
- audio_krsti_full_tari.wav       : Rekaman audio musik tari KRSTI resmi (21.1 MB)
- notebooks/                      : Arsip Jupyter Notebook pelatihan & benchmark
